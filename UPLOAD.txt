ChessGambit — GitHub Desktop 업로드

1. GitHub Desktop > File > Add Local Repository에서 이 ChessGambit 폴더를 선택합니다.
2. Summary 입력 > Commit to main.
3. Publish repository > 이름 ChessGambit > Keep this code private 체크 해제 > Publish repository.
4. GitHub 웹 저장소 > Settings > Pages > Source: GitHub Actions.
5. Actions > Deploy Unity WebGL to GitHub Pages > Run workflow > main > Run workflow.
   최초 실행이 Pages 설정 전에 실패했다면 Re-run all jobs로 재실행합니다.
6. 성공 후 Settings > Pages의 방문 링크를 엽니다.
   kwdmd 계정에서 ChessGambit 이름으로 게시했다면 예상 주소:
   https://kwdmd.github.io/ChessGambit/?lighting=dim

이미 만든 GitHub 저장소를 사용하려면 그 저장소를 Clone한 뒤, 이 폴더에서 .git과 _site를 제외한 내용을 복사하고 Commit > Push origin 하세요. .github와 점으로 시작하는 설정 파일도 포함해야 합니다.

site, chunks, manifest.json, scripts, .github를 모두 올려야 합니다.
_site는 로컬 검증용 복원 결과이며 Git에서 제외됩니다.
GitHubPages/Web 원본 폴더를 추가로 복사하지 마세요. 100MiB 초과 파일이 포함됩니다.
Git LFS, 개인 액세스 토큰, Unity 라이선스 설정은 필요하지 않습니다.
Actions는 Unity를 재빌드하지 않고 분할 파일을 합쳐 SHA-256 검증 후 배포합니다.
새 Unity 빌드를 올릴 때는 조각 파일과 manifest.json을 함께 갱신해야 합니다.
로컬 복원 검증(Node.js 필요): node scripts/assemble.mjs
분할은 업로드를 위한 것으로 방문자의 전체 다운로드 용량은 동일합니다.
